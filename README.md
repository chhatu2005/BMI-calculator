# Day 6 - BMI Calculator

## 📌 Project Overview

The BMI Calculator is a simple web application that calculates a user's Body Mass Index (BMI) based on their height and weight.

The project is developed using HTML, CSS, and JavaScript.

## 🚀 Features

- Enter height in centimeters (cm)
- Enter weight in kilograms (kg)
- Calculate BMI instantly
- Display BMI value up to 2 decimal places
- Display BMI category
- Reset button to clear the input fields
- Simple and user-friendly interface
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📊 BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal Weight |
| 25 - 29.9 | Overweight |
| 30 and above | Obesity |

## 🧮 BMI Formula

BMI is calculated using the following formula:

**BMI = Weight (kg) / Height² (m²)**

The height entered in centimeters is converted into meters before calculating BMI.
